## Overview

Data was extracted from Kaggle and ingested into **Azure Data Lake Gen2** using **Azure Data Factory (ADF)** pipelines. The raw data was then processed and transformed using **Azure Databricks (PySpark)** and stored in the Transformation and Serving layers of the Data Lake.  
The processed data was subsequently loaded into **Azure Synapse Analytics** for analysis and querying, and **Power BI** was connected to verify the connection and preview the dataset for reporting purposes.

## Architecture Diagram (Project Flow)

```
Kaggle Dataset
     ↓
GitHub Repository
     ↓
Azure Data Factory
     ↓
Raw Layer (Data Lake Gen2)
     ↓
Azure Databricks (PySpark)
     ↓
Transformation Layer (Cleaned Data)
     ↓
Serving Layer (Curated Data)
     ↓
Azure Synapse Analytics
     ↓
Power BI (Connected)
```

### Data Lake Architecture

* **Raw Layer**: Stores original data ingested from Kaggle via Azure Data Factory.
* **Transformation Layer**: Contains cleaned and processed data generated by Databricks (PySpark).
* **Serving Layer**: Stores curated, analytics-ready data for Synapse Analytics and Power BI.

## Project Workflow

### 1️⃣ Data Source

* Multiple CSV files for Sales, Product, Customer, etc.

### 2️⃣ Data Ingestion

* **ADF dynamic pipelines** automate data movement
* CSV files → JSON → Raw Layer in Data Lake Gen2
* Pipelines handle multiple files for scalability

### 3️⃣ Data Transformation

* **Databricks (PySpark) notebooks**:

  * Handle missing values and duplicates
  * Standardize formats and column names
  * Save cleaned data to Transformation Layer

### 4️⃣ Data Serving

* Load curated data into **Azure Synapse Analytics**
* Create SQL views for query-ready datasets

### 5️⃣ Data Connection (Power BI)

* Connect Power BI to Synapse
* Preview tables and relationships for reporting

## Getting Started

### Prerequisites

* Azure subscription with Data Lake, Data Factory, Databricks, Synapse access
* Power BI Desktop (for visualization)

### Setup

1. Clone the repository:

```bash
git clone https://github.com/SwathiiKannan/Azure-Data-Engineering-Project.git
```

2. Configure environment variables for Azure credentials (do **not** commit secrets)
3. Open Databricks notebooks in your workspace
4. Run ADF pipelines for ingestion
5. Run Databricks notebooks for transformation
6. Connect Power BI to Synapse for visualization
